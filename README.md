# Olympus Sobeit — Menu 3.0

Репозиторій для збірки **Olympus Sobeit Menu 3.0 (Royal Theme)** — Win32 / GTA SA-MP.

## Стан

- Підготовлено оновлений вихідний код: 9 головних розділів, українські назви, Royal Theme, 12 стилів ESP і налаштування обводки.
- **Нову `d3d9.dll` ще не зібрано та не перевірено в грі.** Початковий код походить із BlackLight Source (версія відрізняється від чинної модифікованої DLL).
- Не замінюйте стабільну `d3d9.dll` неперевіреною збіркою.

## Збірка через GitHub Actions

1. Додайте в корінь репозиторію архів `Olympus_Menu_3_0_Full_Source.zip` із підготовленим вихідним кодом. Архів має містити `BlackLight/src/mod_sa_VS2015.vcxproj` та `build_olympus.ps1`.
2. Після коміту архіву GitHub Actions автоматично запустить **Build Olympus Win32** (можна також натиснути Actions → Build Olympus Win32 → Run workflow).
3. Після успішної компіляції відкрийте запуск і завантажте артефакт `olympus-win32-d3d9` з файлом `d3d9.dll`.
4. Перевірте отриману DLL у **резервній копії** GTA SA, не замінюючи робочу DLL до тесту.

Збірка використовує Visual Studio 2022, Win32 toolset v143 та Microsoft.DXSDK.D3DX з NuGet. Старий проєкт може потребувати додаткових виправлень сумісності. Помилки будуть видні у логах Actions.

## Що зберігаємо

ESP із 12 шрифтами та обводкою, меню Rainbow, раніше погоджені очищення, музика й радіо як порожні розділи. Це **відновлена вихідна реалізація**, ще не валідувана в SA-MP.

Наявна робоча бінарна версія та файли конфігурації користувача не повинні замінюватися цим вихідним кодом без тестування.
